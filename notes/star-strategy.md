# 标星策略（记录，暂不实现）

主人 2026-11-17 晚：参考慧眼选鸟（SuperPicky）的标星策略，先记下来，以后再做。
来源：`../SuperPicky/README_zh.md` 的"评分规则"一节，和 `core/rating_quota.py`、`core/rating_engine.py` 文件开头的说明文字。
慧眼选鸟是 AGPL 协议：这里只记思路，实现时自己写，不抄它的代码。

## 它的做法

核心：**星级是同一批照片互相比出来的**，不是和固定分数线比（4.5.0 版起）。

1. **硬门槛（绝对值，不参与排名、不占名额）**
   - 没有鸟 → 淘汰
   - 检测把握 < 50% → 0 星
   - 头部锐度（按 ISO 归一化）< 100 → 0 星
   - 美学分（TOPIQ，0–10）< 3.5 → 0 星
   - 双眼和嘴都看不见 → 1 星（角度不佳）
2. **综合分** Q = 0.65 × 头部锐度的批内百分位 + 0.35 × 美学的批内百分位
   - 飞鸟 +0.06
   - 对焦点落在鸟头上 +0.04
   - 对焦点落在鸟外面 −0.06（但头部实测锐度很高时认为相机记录有偏差，不扣）
   - 曝光有问题 −0.06
3. **按名额定星**
   - 三星 = Q 排名前 30%（新手档 40%，大师档 20%），并且头部锐度不能低于一个绝对下限
   - 两星 = 其后的 30%
   - 其余一星
   - 开了认鸟时，名额按鸟种分别分配
4. **封顶和保底**
   - 眼睛可见度 < 0.5：最多两星
   - 对焦点在鸟外：最多两星
   - 同一连拍组里三星最多 2 张
   - 每个认出的鸟种至少保住一张两星以上（多数人删 0–1 星、留 2–3 星，不保底会整种丢掉）
5. **写回**：星级、精选旗标、颜色标签（蓝 = 飞版，绿 = 精焦，红 = 对焦有问题）写进 XMP。

## 我们这边的原料

| 它用的 | 我们有没有 |
|---|---|
| 鸟的框和检测把握 | 有（检测模型在换，见 TODO） |
| 头部锐度 | 没有现成的。有眼和嘴的位置（bioclip-bird-heads 的 `parts.py`），可以在眼睛周围算锐度；ISO 归一化要另做 |
| 美学分 | 有：SigLIP2 上的 EVA 头；BioCLIP 第 15 层上的头略差（`distill/aesthetic.py`） |
| 眼睛可见度 | 有，但在没有清楚的鸟的框上不可靠（见 TODO"在主人照片上看鸟眼鸟嘴"） |
| 飞 / 不飞 | 有（bioclip-bird-heads 的 `flight.py`） |
| 对焦点 | 见 TODO 里对索尼原片的验证 |
| 曝光 | Gardener 的 `quality.exposure` |
| 连拍分组 | 之前验证过：拍摄时间间隔 2 秒内算一组（`notes/culling-bench`） |
| 鸟种 | 有 |

## 实现前要定的事

- **单张照片没法用这套办法**（手机场景）：没有"一批"可比。要么用固定分数线，要么只显示分数不给星。主人还没定。
- **怎么检验**：主人的 Lightroom 留片（1 星 = 留下）只做测试，不训练。之前的结论是"组里哪张最好"上 Gardener 和慧眼选鸟都接近随机，所以新策略要在同一批照片上和它们比。
- 权重 0.65 / 0.35 和各个加减分是慧眼选鸟调出来的，换了我们的锐度和美学分之后不一定合适。
